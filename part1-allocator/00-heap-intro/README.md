# heap-intro

프로세스의 메모리 영역 중 힙 영역에 대해 알아보고, 
힙 메모리 할당과 해제 방법(사용자 관점), gdb에서 힙 메모리를 관찰하는 방법에 대해 다룬다.

자세한 내용은 이 문서에서 다루지 않는다.

---

## 1. 힙(Heap) 영역

프로세스의 메모리는 다음 5개의 영역으로 나눌 수 있다.

- Text(Code) 영역: 실행할 기계어 명령어들. 읽기 전용.
- Data 영역: 초기화된 전역/정적 변수.
- BSS 영역: 초기화 안 된 전역/정적 변수. 실행 시 0으로 초기화 됨.
- Heap 영역: 동적으로 할당하는 메모리.
- Stack 영역: 함수 호출 스택, 지연 변수.

가상 메모리 상으로는 대략 다음과 같은 배치를 가진다.

```
높은 주소
+-------------+
|   Stack     | ↓ 아래로 자람
+-------------+
|             |
+-------------+
|   Heap      | ↑ 위로 자람
+-------------+
|    BSS      |
+-------------+
|    Data     |
+-------------+
|    Text     |
+-------------+
낮은 주소
```

# 2. 메모리의 할당과 해제

## 2.1 메모리 할당

### malloc

``` c
void *malloc(size_t size);
```

- `size` 바이트만큼 힙에서 메모리를 할당해 달라고 요청.
- 성공하면 그 메모리의 시작 주소(포인터) 반환, 실패하면 NULL.
- 초기화를 하지 않음 : 할당된 메모리 안에 쓰레기값이 들어있을 수 있음.

### calloc

``` c
void *calloc(size_t nmemb, size_t size);
```

- `size` 바이트 크기의 메모리 `nmemb` 개를 할당 : 총 `size` * `nmemb` 바이트 할당.
- 0으로 초기화 함.

### realloc

``` c
void *realloc(void *ptr, size_t size);
```

- 이미 할당된 `ptr` 메모리를 `size` 크기로 재조정
- 기존 데이터는 최대한 유지, 필요 시 다른 위치로 옮기고 기존 위치는 알아서 해제

## 2.2 메모리 해제

``` c
void free(void *ptr);
```

- `ptr`이 가리키는 메모리를 힙 allocator한테 반납.
- 반납된 메모리는 물리적으로 지워지는 것이 아니라, allocator가 다시 쓸 수 있는 블록으로 관리 목록에 추가함.
- 데이터 자체는 그대로 남아있을 수 있음.

# 3. gdb

### 메모리 확인

힙 영역의 메모리도 `x` 명령어를 사용하여 확인이 가능하다.

`x` 명령어의 포맷은 `x/[개수][단위][포맷]` 구조이다.

```
x/gx <addr>     # 8바이트(giant) 단위로 hex 출력
x/4gx <addr>    # 8바이트씩 4개 출력
x/20xb <addr>   # 1바이트씩 20개 출력
x/s <addr>      # 문자열로 출력
```

### pwndbg 명령어

순수 gdb만으로 힙 구조를 보는 것이 번거로울 때 사용할 수 있는 pwndbg의 명령어들이다.

```
vmmap           # 메모리 맵 확인 (heap이 어디서부터 어디까지인지)
heap            # 힙에 있는 모든 청크를 순서대로 나열 (크기, 상태 포함)
bins            # tcache, fastbin, unsorted bin 등 모든 bin 상태 한눈에 보기
tcache          # tcache 상태만 따로 보기
fastbins        # fastbin 상태만 보기
unsortedbin     # unsorted bin 상태만 보기
chunk <addr>    # 특정 주소를 청크로 해석해서 헤더(size, flags) 정보 출력
chunkinfo       # 현재 청크들 요약 정보
vis_heap_chunks # 힙 전체를 시각적으로(색깔 구분) 쭉 보여줌 — 제일 많이 쓰게 될 명령어
telescope <addr> [개수]  # 해당 주소부터 메모리를 죽 훑으면서 포인터인지 값인지 자동 판별해서 보여줌
```
